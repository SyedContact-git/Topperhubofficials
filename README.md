# TopperHub - Study Platform

A comprehensive study platform aggregating content from 8 top education platforms.

## Platforms

| Platform | Features |
|----------|----------|
| **KGS** | Batches, Subjects, Video Lessons, PDFs |
| **Padhle** | Folder Hierarchy, Live Classes, Video Player, Notes |
| **Science And Fun** | Folder Hierarchy, Live Classes, Videos |
| **Vibrant Academy** | Folder Hierarchy, Live Classes, Videos |
| **MissionJeet** | Batches, Live Classes |
| **NextToppers** | Batches, Live Classes, DRM Videos |
| **RWA (Rojgar With Ankit)** | Batches, Subjects |
| **Physics Wallah (PW)** | Batches, Subjects, Topics, Videos, DRM, Attachments |

## Features

- Browse all platforms and their batches with images
- Navigate content hierarchies (subjects, topics, folders)
- Watch live and recorded video classes
- View upcoming and completed live classes
- Download notes and PDFs
- Responsive dark-themed UI
- Search and filter across platforms and batches

## Tech Stack

- **React 19** + **Vite**
- **React Router** for navigation
- Vanilla CSS with CSS variables (dark theme)
- API Base: `https://apiserver-jwex.onrender.com`

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
